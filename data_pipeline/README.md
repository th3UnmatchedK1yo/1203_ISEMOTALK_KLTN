# Data pipeline

- corpus_registry.json: machine-readable inventory and task assignments for every candidate corpus.
- audit.py: metadata/audio audit and grouped development folds for the existing core corpora.
- inspect_archive.py: non-extracting ZIP inventory for MELD-VIET and other archives.
- Raw data and generated manifests stay outside this Git checkout.
- The KLTN is academic/non-commercial. Research-use sources are included; preserve attribution and access acknowledgements.
